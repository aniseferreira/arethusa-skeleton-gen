# arethusa-skeleton-gen
*Arethusa XML Skeleton Generator* for sentences to be annotated in the Arethusa editor within the Perseids platform - perseids.org. The Perseids platform has stopped generating source code for annotating the AGDT Treebank; however, it still allows users to import non-annotated XML files ready to be treebanked and to view previous annotations. 

This app generates an XML file with parsed sentences, in the Arethusa treebank AGDT format used in Perseids Platform. 

By Anise Ferreira, carried out with the assistance of Gemini/Google Workspace/AI.


*Gerador de Esqueleto XML Arethusa*  para sentenças a serem anotadas no editor Arethusa dentro da plataforma Perseids
Solicitado por Anise Ferreira para Gemini/Google Workspace/AI. 

A plataforma Perseids parou de gerar o código-fonte para a anotação do Treebank AGDT, mas continua aceitando a importação de XML e a visualização de anotações anteriores.
Este aplicativo gera um arquivo XML com períodos separados, no formato AGDT do editor de árvores sintáticas de dependência Arethusa utilizado na Plataforma Perseids.
